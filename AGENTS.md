Na sessão de cadastro, quando o cadastro for feito com o seletor de modo de usuario na posição "psicólogo":

# Formulário de login
- crp precisa de máscara
- adicionar campo abordagem(ns)
- adiconar campo especialidades
- precisa de uma lista de especialidades pré definidas, cadastradas via owner de plataforma (Gerar umas 50 especialidades de psicologia iniciais, consulte plataformas de psicologia existentes como psymeet, telavita, psicologia viva e zenklub)

# Geral
- quando a aplicação executar, deve ser feito um seed para uma conta owner inicial
- precisa de uma lista de abordagens pré definidas, cadastradas via owner de plataforma (Gerar uma quandidade inicial adequada das abordagens principais de psicologia)
- o applicativo deve ter 3 homes, de usuario paciente, de usuario psicólogo e de owner, que poderá editar a lista de abordagens e especialidades
  
# Home Paciente
- na home de paciente a plataforma deve entregar a lista de psicólogos disponíveis. deve ter filtros por especialidade, abordagem, valores de sessão (deve ser um campo adicionado aos dados por parte do psicólogo)

### Master View Detail

#### Master-View
- a listagem de psicólogos devem ter: nome, foto (deve ter uma seção na tela de psicólogo para cadastro de foto de perfil), abordagem, especialidades, valor de sessão.
- quando a pessoa abre o perfil de psicólogo em questão
- como o preço de sessão é um valor opcional por parte do psicólogo, ele deve ser exibido apenas se o psicólogo fornecer

#### Detail
- Solicitação de contato através de formulário
- Todas as infos de Master-View
- Descrição / bio
- Whatsapp
- Instagram

- Outros

# Home Psicólogo 
- na home de psicólogo ele deve ver as solicitações de contato por parte dos pacientes enviadas via formulário
- campos para cadastrar todos os dados acima mencionados
